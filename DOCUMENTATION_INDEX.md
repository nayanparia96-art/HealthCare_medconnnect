## 🧪 Testing Paths

### Quick Test (10 minutes)
1. Follow [GET_STARTED_5_MIN.md](GET_STARTED_5_MIN.md) Steps 1-5
2. Test form at http://localhost:8000/apply/
3. Submit test data
4. Check console for confirmation email
5. Access admin at http://localhost:8000/admin/

### Full Test (30 minutes)
1. Cover above
2. Test each form field (empty, invalid, valid)
3. Try uploading different file types/sizes
4. Test admin filtering
5. Test status updates
6. Try custom email configuration

### Production Test (1-2 hours)
1. Configure Gmail SMTP
2. Test real email delivery
3. Load test (multiple submissions)
4. Admin performance test
5. Database backup/restore
6. Security scan
