## Complete Features Available

### 1. User Management
- **Registration:** Create new accounts
- **Login/Logout:** Secure authentication
- **Profile:** View and edit personal information

### 2. Healthcare Services
- **Book Appointment:** Schedule with doctors
- **My Appointments:** View all scheduled appointments
- **Doctors List:** Browse all specialists
- **Patients List:** View patient records
- **Medicines:** Online pharmacy with stock info
- **Blood Bank:** Check blood availability
- **Feedback:** Submit complaints/suggestions
- **Ambulance:** Emergency contact information

### 3. Navigation & UX Features
- **Dynamic Navigation:** Changes based on login status
- **Breadcrumb Navigation:** Easy page navigation
- **Emergency Button:** Floating ambulance access on all pages
- **Comprehensive Footer:** Quick links and contact info
- **Responsive Design:** Works on all devices
